# Nori · descargas

Aquí están las apps de [Nori](https://kizuna-steel.vercel.app/conoce) para Windows, Mac y Linux, en
[Releases](https://github.com/Riscooo/nori-descargas/releases).

La forma fácil de conseguirlas es la página **[Descargar](https://kizuna-steel.vercel.app/descargar)**,
que te dice cuál es la tuya y cómo instalarla. Una vez instaladas, se ponen al día solas.
